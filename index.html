📲 Instalar NavVision

❓ ¿Cómo Funciona NavVision?

1. Modo Emisor: La persona ciega lleva el móvil y el wearable ESP32 con sensor ultrasónico conectados por Bluetooth.

2. Conexión ESP32: Pulsa "CONECTAR WEARABLE ESP32". Busca el dispositivo llamado NavVision-ESP32. Al conectar, el código de sesión se sincroniza automáticamente.

3. Rastreo GPS: Transmite la posición en tiempo real hacia Supabase para que el tutor la vea en el mapa.

4. Receptor: Introduce el código de 6 caracteres para seguir al emisor en el mapa.
